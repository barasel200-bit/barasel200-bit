# AI video tools worth trying

I keep a short list of browser-based AI video and image tools I actually use for quick
prototypes — text-to-video, image-to-video, reverse search and prompt references.
No affiliate links, just the sites.

### Video generation
- [H3 Video](https://h3video.org/) — cinematic text-to-video clips in the browser.
- [Seedance 2.5](https://seedance25.kr/) — smooth motion clips from text and image prompts.
- [Viddi AI](https://viddiai.com/) — text or image to short video, fast.
- [Wan 3](https://wan-3.io/) — open model for text-to-video and image-to-video.
- [Kling 4](https://kling4.co.kr/) — Korean walkthroughs and prompt examples for Kling.
- [Pavo AI](https://pavoai.app/) — studio-style short clip generation with style controls.
- [GTA 6 AI Video](https://gta6aivideo.art/) — game-look cinematic clips from prompts.

### Image and search
- [Grok AI Image Generator](https://grokaiimagegenerator.net/) — free image generation in browser.
- [Reverse Video Search](https://reversevideosearch.org/) — find a clip's source and similar scenes.

### Audio
- [Memories Song](https://memoriessong.com/) — turn personal stories into custom songs.

### Benchmarks
- [AI video benchmarks](https://barasel200-bit.github.io/ai-video-benchmarks/) — notes on latency,
  prompt adherence and clip length across the tools above.
